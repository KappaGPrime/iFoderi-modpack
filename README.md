# iFoderi Second Dawn [2.0]

Modpack del server **iFoderi**. Si installa una volta sola con Prism Launcher: da lì in poi **le mod si aggiornano da sole** ogni volta che avvii il gioco.

## Installazione (una volta sola)

### 1. Installa Prism Launcher
Scaricalo da **https://prismlauncher.org/download** (Windows: "Installer") e installalo.
Se ce l'hai già, salta questo passo.

### 2. Aggiungi il tuo account
In Prism, in alto a destra: **Account → Gestisci account → Aggiungi Microsoft** e accedi.
Se non hai un account Minecraft originale, chiedi allo staff come entrare.

### 3. Scarica l'istanza
Scarica questo file (non aprirlo, basta salvarlo):
**[iFoderi-Second-Dawn-2.0.zip](https://github.com/KappaGPrime/iFoderi-modpack/releases/download/istanza/iFoderi-Second-Dawn-2.0.zip)**

### 4. Importala in Prism
1. In Prism clicca **Aggiungi istanza** (in alto a sinistra).
2. A sinistra scegli **Importa**.
3. Clicca **Sfoglia**, seleziona il file `iFoderi-Second-Dawn-2.0.zip` appena scaricato e premi **OK**.

Comparirà l'istanza **iFoderi Second Dawn [2.0]** con il logo dei Foderi.

### 5. Avvia
Fai doppio clic sull'istanza. **La prima volta** si apre una finestrella che scarica tutte le mod: ci vuole qualche minuto, lasciala finire. Poi parte Minecraft.
Il server **iFoderi** è già nella lista dei server multigiocatore.

## Gli aggiornamenti
Non devi fare niente: a ogni avvio la finestrella controlla se c'è una versione nuova e scarica solo quello che è cambiato (pochi secondi).
**Non mettere e non togliere mod a mano** dalla cartella mods: verrebbero rimesse a posto al prossimo avvio.

## Hai già la vecchia istanza?
Puoi tenere le tue mappe e i waypoint della minimappa:
1. In Prism, tasto destro sulla **vecchia** istanza → **Cartella** e apri la cartella `minecraft`.
2. Copia la cartella **`xaero`**.
3. Tasto destro sulla **nuova** istanza → **Cartella** → `minecraft` e incollala lì (sostituisci se te lo chiede).

Poi la vecchia istanza la puoi cancellare.

## Problemi?
- **La finestrella dice che un download non è riuscito**: chiudi e riavvia il gioco, riprova da sola.
- **Il gioco è lento o si chiude per memoria**: tasto destro sull'istanza → **Modifica → Impostazioni → Memoria** e alza la "Memoria massima" (consigliati 6-8 GB se il PC ne ha almeno 16).
- Per tutto il resto scrivi nel gruppo Telegram.
